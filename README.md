Café Lumière

A modern and elegant café website UI/UX design created in **Figma**, focusing on a clean visual experience, intuitive navigation, and a welcoming café atmosphere.

🎨 Design Preview

The project was designed using Figma with a focus on:

* Clean and modern visual design
* User-friendly navigation
* Café menu presentation
* Attractive typography and layout
* Responsive web design concepts
* Simple and intuitive user experience
